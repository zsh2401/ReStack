# 会话归档

将当前会话中的研究成果、讨论内容、关键决策总结为结构化文档，保存到项目 `docs/` 目录。

## 触发时机

- 用户说"归档"、"保存会话"、"记录下来"、"docify"
- 一段深入的技术探讨或研究发现结束时
- 用户想保留上下文以便后续查阅

## 文件结构

```
<项目根目录>/docs/
└── YYYY-MM-DD-<研究标题>/
    ├── index.md          # 正文（必需）
    ├── assets/           # 附件（可选）
    │   ├── image.png
    │   └── data.csv
    └── references.md     # 引用清单（可选）
```

## 工作流程

### 1. 确定标题

根据会话核心主题提炼简短标题，格式：`YYYY-MM-DD-<topic>`。

示例：
- `2026-06-02-transformer-architecture-review`
- `2026-06-02-深度学习编译优化调研`

标题只含小写字母、数字、连字符。

### 2. 生成 index.md

在 `<项目根目录>/docs/<YYYY-MM-DD-<topic>/index.md` 中生成正文，格式：

```markdown
---
date: YYYY-MM-DD
topic: 研究主题
tags: [tag1, tag2]
---

# 标题

## 背景
<为什么要做这个研究>

## 关键发现
<核心发现，带来源引用>

## 讨论
<分析、对比、决策理由>

## 结论与下一步
<总结 + 行动项>

## 来源
- [来源1](url)
- [来源2](url)
```

### 3. 收集附件

如果会话中涉及图片、数据表、代码片段等，保存到 `assets/` 子目录，在 `index.md` 中引用。

### 4. 清理确认

生成后向用户输出文档路径和文件清单，确认归档完成。
